MICROSOFT EDGE / LOCAL EXTENSION

HKU Piano Companion

A two-button companion for portal login and a single scheduled room reservation. No Python installation or saved-cookie file is needed.

Install once

  1. Keep the extracted folder in a permanent location.
  2. Enter edge://extensions in Microsoft Edge's address bar.
  3. Enable Developer mode, then click Load unpacked.
  4. Select the folder containing manifest.json.
  5. Open HKU Piano Companion from Edge's Extensions menu.

First run: no booking

Click Portal login and finish SSO/2FA. In Reservation, enter a future room slot and your details. Choose Prepare now, keep Rehearsal only checked, and confirm. Complete a CAPTCHA manually when prompted. A rehearsal never clicks Create.

Then authorize a real attempt

Choose Scheduled release, enter its date and time in Hong Kong time, and adjust the early-opening and click-offset settings. Uncheck Rehearsal only, review, and confirm.

Keep the companion and HKU tab open, and keep the computer awake. Read the captured HKU response; a sent click is not confirmation. No automatic retry is made.

Local verification is required. The code passed helper and simulated-browser checks, but authenticated HKU pages and an actual Edge installation were not tested here. Use rehearsal before relying on it. For live availability, use HKU's own calendar and import its selected slot if its links cannot be read automatically.
